# 🍽️ Foodie Restaurant Website

Foodie Restaurant is a responsive restaurant frontend website built using HTML, CSS, and JavaScript. It provides an attractive interface where users can explore food items, search the menu, filter dishes by category, and try a table booking form.

## ✨ Features

- **Responsive Design:** Works on desktop, tablet, and mobile screens.
- **Food Menu:** Displays different vegetarian food items.
- **Category Filtering:** Filter menu items by category.
- **Live Search:** Search for food items by name.
- **Table Booking Form:** Enter personal details and select booking preferences.
- **Form Validation:** Checks user input before submitting the booking.
- **Booking Confirmation:** Displays a confirmation modal with booking details.
- **Print Booking Slip:** Users can print their booking details.
- **Recent Bookings:** Saves recent demo bookings in browser local storage.

## 🛠️ Technologies Used

- HTML5 – Website structure
- CSS3 – Styling and responsive layout
- JavaScript – Search, filtering, form validation, and booking interactions


## 📸 Website Sections

- Navigation Bar
- Hero Section
- Chef's Specials
- Food Menu
- Table Booking Section
- Booking Confirmation Modal
- Footer

## ⚠️ Important Note

This project is a **front-end demonstration website**.

The table booking feature is created for demonstration purposes only. It does not connect to a real restaurant, server, or database. Booking details are stored locally in the browser using Local Storage.

## 🎯 Project Objective

The main objective of this project is to practice front-end web development and understand how HTML, CSS, and JavaScript work together to create an interactive and responsive website.
